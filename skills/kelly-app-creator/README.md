# Kelly App Creator

Kelly App Creator designs recurring human-and-Agent workflows on Busabase. It is a product workflow layer, not a second application framework.

It requires:

- `$busabase` for connection, workspace operations, ChangeRequests, and approvals;
- `$busabase-app-creator` for Busabase resources, Vault boundaries, AirApp engineering, validation, and deployment.

The default operating model is Research -> Plan -> Action -> Retrospective. Kelly App Creator contributes app-type patterns, human attention and opt-out rules, Agent responsibilities, approval points, and retrospective feedback. It does not support a local provider or define its own runtime/data layer.

Invoke it when designing research desks, review queues, planners, action consoles, operating dashboards, control panels, or collaboration workspaces.
